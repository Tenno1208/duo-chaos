## 🚀 Tentang Project Ini
**DUO CHAOS** adalah platform web *party game* multiplayer real-time yang dirancang untuk menghidupkan suasana tongkrongan atau mabar virtual. Tanpa perlu download aplikasi, cukup buat room, share kode atau link ke teman, dan mainkan berbagai mini-game konyol yang siap menghancurkan persahabatan (dalam arti baik)! 😈

---

## ✨ Fitur Unggulan

- ⚡ **Real-Time Multiplayer** – Sinkronisasi state game seketika tanpa delay berkat Supabase Realtime.
- 🎨 **Custom Avatar & Profiles** – Pilih avatar kocakmu sendiri sebelum bertanding.
- 🎭 **Live Emote Overlay** – Spam reaksi emoji dan stiker langsung di layar saat game berlangsung.
- 👁️ **Spectator Mode** – Room penuh? Teman tetap bisa gabung sebagai penonton (Spectator) dan meramaikan suasana.
- 🔄 **Rematch & Voting System** – Tanding ulang langsung dengan sekali klik setelah game selesai.
- 🛠️ **Maintenance Mode with Minigames** – Halaman maintenance elegan dengan hitung mundur otomatis dan mini-game tersembunyi (*Chaos Catcher*).

## 💻 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Database & Auth:** [Supabase](https://supabase.com/) (PostgreSQL & Realtime WebSockets)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animation:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

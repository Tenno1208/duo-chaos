## 💎 Tentang DUO CHAOS

> ⚜️ ***DUO CHAOS*** adalah platform web *party game* multiplayer real-time bergaya modern dengan estetika visual yang **mewah dan imersif**. Dirancang khusus untuk mencairkan suasana — baik saat nongkrong bareng di kafe, arisan keluarga, maupun mabar jarak jauh secara virtual.

Tanpa instalasi ribet, tanpa repot *download* aplikasi tambahan. Cukup buka *browser*, buat *room*, bagikan tautan unik ke teman-temanmu, dan nikmati pengalaman bermain game kompetitif yang seru dan penuh kekacauan menyenangkan! Satu *link* untuk semua orang — di HP, laptop, maupun tablet.

## 💻 Tech Stack & Arsitektur

Project ini dibangun di atas fondasi teknologi web modern berkinerja tinggi:

- **Framework:** [Next.js](https://nextjs.org/) — App Router & Server Components
- **Database & Auth:** [Supabase](https://supabase.com/) — PostgreSQL, Row Level Security, & Realtime WebSockets
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) — desain responsif dan elegan
- **Animation:** [Framer Motion](https://www.framer.com/motion/) — transisi UI yang mulus dan imersif
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

## 🛠️ Instalasi & Menjalankan di Lokal

Ingin mencoba menjalankan atau memodifikasi **DUO CHAOS** di komputer lokalmu? Ikuti langkah-langkah di bawah ini:

### 📋 Prasyarat

Pastikan komputer kamu sudah menginstal:

- [Node.js](https://nodejs.org/) — versi 18 atau terbaru disarankan
- [Git](https://git-scm.com/)
- Akun [Supabase](https://supabase.com/) (gratis) untuk database & realtime

### 1️⃣ Clone Repository

```bash
git clone https://github.com/USERNAME_KAMU/duo-chaos.git
cd duo-chaos
```

### 2️⃣ Instal Dependencies

```bash
npm install
```

### 3️⃣ Setup Environment Variables

Buat file `.env.local` di root project, lalu isi dengan kredensial Supabase milikmu:

```env
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
```

### 4️⃣ Jalankan Development Server

```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser, buat room, dan mulai kekacauannya! 🎉
